
## 1. Product Overview
一款沉浸式英语学习在线教育平台，基于剑桥体系课程设计，提供互动式学习体验、进度追踪和个性化学习路径。
- 目标用户：各年龄段英语学习者，从入门到精通
- 市场价值：结合传统剑桥体系与现代互动学习，提升学习效率和趣味性

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| Normal User | Email/账号注册 | 浏览课程、完成练习、追踪进度、社区交流 |

### 2.2 Feature Module
1. **首页**：课程概览、学习进度、推荐内容
2. **课程中心**：剑桥体系课程（KET、PET、FCE、CAE、CPE）
3. **学习模块**：单词记忆、语法练习、口语跟读、听力训练、短文跟读、写作练习
4. **学习进度**：进度追踪、学习统计、成就系统
5. **社区**：话题讨论、学习打卡、经验分享
6. **个人中心**：用户信息、学习路径、设置

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 首页 | Hero区 | 平台介绍、核心特色、CTA按钮 |
| 首页 | 学习仪表盘 | 今日学习、进度概览、推荐任务 |
| 课程中心 | 课程列表 | 剑桥五级课程体系、课程详情、开始学习 |
| 单词记忆 | 闪卡模式 | 单词展示、释义、发音、记忆测试 |

## 3. Core Process
用户注册登录后，系统根据水平测试推荐初始课程。用户可选择课程进入学习，完成单词、语法、口语、听力等互动模块。学习数据实时同步，在个人中心查看进度和成就。在社区与其他学习者交流分享。

```mermaid
flowchart TD
    A[用户注册/登录] --&gt; B[水平测试/选择课程]
    B --&gt; C[开始学习]
    C --&gt; D[互动学习模块]
    D --&gt; E{完成练习?}
    E --&gt;|是| F[更新进度/获得成就]
    E --&gt;|否| D
    F --&gt; G[社区交流]
    G --&gt; C
```

## 4. User Interface Design
### 4.1 Design Style
- Primary color: 蓝紫色渐变 (#6366f1 to #8b5cf6)
- Secondary color: 暖橙色 (#f59e0b)
- Button style: 圆角矩形、微渐变、悬浮效果
- Font: Inter + Space Grotesk
- Layout style: 卡片式布局、侧边导航
- Icon style: Lucide图标库，线性风格

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 首页 | Hero区 | 大标题、平台特色图标、动画效果、渐变背景 |
| 课程中心 | 课程卡片 | 课程封面、等级标识、进度条、悬停放大 |
| 学习模块 | 练习界面 | 居中布局、大按钮、动画反馈、进度指示 |
| 学习进度 | 仪表盘 | 环形进度条、数据卡片、彩色图表 |
| 社区 | 动态流 | 瀑布流卡片、头像、时间戳、互动按钮 |

### 4.3 Responsiveness
Desktop-first，移动端自适应设计，支持触摸操作

### 4.4 3D Scene Guidance
不适用
